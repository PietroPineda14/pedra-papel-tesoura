# Pedra, Papel ou Tesoura

Um jogo simples de **Pedra, Papel ou Tesoura** feito em Python, onde o jogador enfrenta o Ted, que faz as escolhas de forma aleatória.

## Como funciona

O jogador escolhe uma das três opções:

* Pedra
* Papel
* Tesoura

Depois da escolha, o computador escolhe uma opção aleatória e o programa mostra o resultado da partida.

## Tecnologias utilizadas

* Python
* Biblioteca `random`

## Como executar

1. Tenha o Python instalado no computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute o arquivo Python pelo terminal:

```bash
python nome_do_arquivo.py
```
